Git Worktree Isolation

Isolamento físico de código por branch (`.worktrees/slice-N`). Zero contaminação de workspace e conflitos de merge nulos.

Iron Law of TDD

Local Worker GPU: Privacidade Total e Custo Zero de API

  • Engine Local: Ollama com suporte a Q4_K_M
  • Modo Cirúrgico: Diff blocks com validação semântica
  • Garantia de Entrega: Circuit breaker com inteligente fallback
  • Acesso FIFO: LocalWorkerQueue protegendo VRAM contra OOM
